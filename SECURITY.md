# TCSA public repository — data segregation
This repository is PUBLIC. Publish only sanitized source code, schemas, documentation and examples.
Never commit private checkpoints, transcripts, executable journals, tokens, passwords, machine backups, local user datasets, private repository contents, large recovery archives, or historical records.
Operational archives are retained in private Google Drive and recoverable local backups. Public code reads private data only when run with explicit authorized access.
A checkpoint summary is not a backup. Verify original bytes, SHA-256, receipts and restore tests before claiming recovery.
